# 3D charts

3D is an add-on: the packages `Tachyon.Charts.ThreeD` and `Tachyon.Charts.ThreeD.Wpf` or `Tachyon.Charts.ThreeD.Avalonia` build on the 2D charts. A 3D chart rests on a 2D chart, so render thread, themes, languages, text, export and video work as in 2D. The 2D packages know nothing of 3D.

3D needs a graphics card. Without one, `Chart3D.IsGpuAvailable` is `false`, the event `GpuUnavailable` fires and the chart shows a short note instead of the picture. `Gpu3d.Status` tells it before you create a chart.

## The shortest 3D chart

```csharp
using Tachyon.Charts.Core.Data;
using Tachyon.Charts.Core.Numerics;
using Tachyon.Charts.ThreeD.Scene;
using Tachyon.Charts.ThreeD.Wpf; // or Tachyon.Charts.ThreeD.Avalonia

var heights = new HeatmapData(200, 200);
var values = new float[200 * 200];
for (var i = 0; i < values.Length; i++)
{
    var (x, y) = (i % 200 / 20.0, i / 200 / 20.0);
    values[i] = (float)(Math.Sin(x) * Math.Cos(y));
}

heights.SetValues(values);
var chart = new Chart3D().Configure(c => c
    .Title("Surface")
    .XAxis(0, 10, "x")
    .YAxis(0, 10, "y")
    .ZAxis(-1, 1, "z")
    .AddSurface(new Surface3D(heights, new DoubleRange(0, 10), new DoubleRange(0, 10))));
```

Put `chart` into your window like any other control. `chart.Scene` gives the scene, its axes, its camera and its markers.

## Mouse and keyboard

| Input | Effect |
|---|---|
| Drag | Turn the view around the box |
| Shift+drag, middle button | Move the view |
| Wheel | Zoom |
| Arrow keys | Turn in steps |
| Double click, Home | Back to the start view |
| Pointer | Value under the pointer |
| Click | Set a marker; a click on a marker removes it |
| Delete | Remove the newest marker |
| Drag an orange outline | Move a cut plane |

`chart.Scene.Camera` turns, zooms and shows fixed views from code: `Orbit`, `Pan`, `Zoom`, `Show(CameraView.Top)`. `.Projection(CameraProjection.Orthographic)` shows the box without perspective.

## Themes and languages

`.Theme(BuiltInThemes.Paper)` in the builder or `chart.ChartTheme` later colors the background, the box, the grid and the text, as in 2D. The texts under the pointer follow `ChartText.Language`.

## Values from code

`Pick3DProbe.Find(scene, x, y)` finds what lies under a point of the picture, with the same rules as the pointer. Markers are in `scene.Markers`; `AddMarker`, `RemoveMarker` and `RemoveLastMarker` change them.

## Export and video

A 3D chart exports to PNG in any size, to SVG and PDF with the picture embedded, and to CSV with x, y, z and value; it records videos like a 2D chart. See [export](export.md).
